Homework Writer Billing checks

01  What this covers

The billing functions run on Netlify, which needs Node — so these checks import the real function modules and exercise the parts that do not need a server: the Stripe webhook signature check, the free-allowance arithmetic, the monthly reset, and the form encoding used for Stripe calls. Anything touching Netlify Blobs, Stripe's API or Google's token endpoint can only be exercised on a deploy.
